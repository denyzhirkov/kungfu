Зафиксированные решения (2026-05-29):
- Движок: candle (pure Rust, без native deps). Решение продиктовано простотой дистрибуции.
- Модель: BAAI/bge-small-en-v1.5 (384-dim, English-only, ~130MB). Доступна на HuggingFace.
- Хранение весов: ~/.cache/kungfu/models/<model_id>/ (XDG-конвенция, шарится между проектами).
- Embedding index в проекте: .kungfu/index/embeddings.bin (raw f32 LE, append-only) + embeddings.manifest.json (model_id, dim, symbol_id→offset, digest blake3 для stale-детектора).
- Default behaviour: OPT-IN через флаг `--features semantic` при сборке или config `[semantic] enabled = true`. Без флага — fallback на существующий query-expansion.

Текущий статус (v2.1.x): отгружен ТОЛЬКО scaffold:
- Новый крейт kungfu-embed с трейтом EmbedEngine, NoopEngine, EmbeddingManifest, cosine/l2_normalize, default_models_dir.
- Hook в kungfu-core/search_ops.rs::semantic_search: проверяет manifest, вызывает open_default_engine().embed_batch — Noop возвращает Err и мы падаем в keyword-путь.
- CLI: `kungfu embeddings status|install|build`. status работает; install/build печатают что нужна feature.

Чтобы доделать (отдельная фокусированная сессия):
1. Раскомментировать в crates/kungfu-embed/Cargo.toml deps candle-core/candle-nn/candle-transformers/tokenizers/hf-hub и feature inference.
2. В kungfu-embed::src/lib.rs реализовать CandleEngine::load (hf-hub download → BertModel::load) и embed_batch (tokenize → forward → mean-pool → l2_normalize).
3. open_default_engine() должен возвращать CandleEngine при cfg(feature = "inference"), иначе Noop.
4. Дополнить CLI: install (hf-hub::api::sync скачивает в default_models_dir), build (итерация по символам, batched embed, append в embeddings.bin, save manifest).
5. В semantic_search дочитать embeddings.bin как mmap, перевести в Vec<[f32;DIM]>, посчитать cosine с query-вектором, top-K.
6. Тест: на собственном репо проверить, что запрос "auth" находит "verify_token" в индексе.

Запас на размер бинарника: candle добавит ~50-100MB к release-бинарнику. Для дистрибуции через npm/install.sh оставим default-сборку без candle, а semantic — отдельный артефакт kungfu-semantic.
