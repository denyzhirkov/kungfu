Все library crates (всё кроме kungfu-cli, kungfu-mcp, kungfu-bench) имеют в начале lib.rs:

    #![cfg_attr(not(test), deny(clippy::unwrap_used, clippy::expect_used))]

Запрет включается только для production-кода; в тестах `unwrap()` по-прежнему допустим. Это форсирует выполнение правила CLAUDE.md «no unwrap/expect in library crates» на уровне компиляции, а не code review.

Конвенция при нарушении:
- Result-возвраты — `?` с осмысленным thiserror-вариантом.
- Опциональные — `if let Some(x) = ...` / `ok_or_else` / `unwrap_or_default`.
- Для редких safe-by-construction случаев (например, `serde_json::json!({...}).as_object_mut()`) — переписать на `if let`, а не вешать `#[allow]`.

Clippy gate `cargo clippy --workspace --all-targets -- -D warnings` обязан быть зелёным.
