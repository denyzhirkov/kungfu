`git log --format=COMMIT` фейлится с "invalid --pretty format: COMMIT", но `Command::output()` не считает это ошибкой (ненулевой exit + пустой stdout). Из-за этого co_change_pairs тихо возвращал пустой результат, и `coupling` показывал co_change_count = 0 для всех файлов.

Правило: для литеральных разделителей всегда `--format=format:LITERAL` (или `--pretty=format:LITERAL`). Без префикса `format:` git трактует значение как имя preset-формата.

Связанное: `co_change_pairs` и `file_churn` в kungfu-git до сих пор не проверяют exit status / stderr. Имеет смысл отдельной задачей добавить проверку для всех git-вызовов, чтобы такие silent failures ловились на месте.
