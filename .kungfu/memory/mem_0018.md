Эпик 4 must-have плана (7tf63o), v2.5.15. Вектора из коробки и самоподдерживающиеся.

1. ДИСТРИБУЦИЯ: kungfu-cli default = ["semantic"] (candle компилится по умолчанию; +4MB бинарь, candle в cargo-кэше). Opt-out: cargo build --no-default-features. Setup сжат до ОДНОЙ команды: kungfu embeddings build — авто-скачивает веса при отсутствии (install_model вызывается из build; в kungfu-embed добавлен stub install_model для no-feature сборок, чтобы core звал безусловно без cfg-лапши).

2. ИНКРЕМЕНТАЛЬНОСТЬ: новый KungfuService::embeddings_sync() (embeddings.rs) — дешёвый digest-diff ДО загрузки модели; no_store (манифеста нет — не авто-opt-in) | no_engine (нет весов — не авто-качает) | up_to_date | synced. Общий embed_pending(...) для build/sync. kungfu_embed::prune_and_compact(index_dir, manifest, live_ids): дроп манифест-записей мёртвых символов + перезапись embeddings.bin при >25% мёртвых строк (или маленьком файле); атомарно tmp+rename. ВАЖНО: symbol ids включают content-hash файла → каждый реиндекс меняет все ids файла → без prune store рос бесконечно (был 1405 при 923 живых, top_k терял слоты на мёртвых). prune теперь и в build, и в sync.

3. ФОНОВАЯ СИНХРОНИЗАЦИЯ (mem_0008 — инференс НИКОГДА в request-path): cache.rs: static EMBED_JOB_RUNNING (один джоб на процесс) + spawn_embeddings_sync(root) — поток с собственным KungfuService. Вызывается после reindex-тула и после авто-реиндекса в service(). MCP embeddings_build ТОЖЕ переведён в фон (был синхронный — блокировал MCP на минуты!): возвращает started/already_running + hint поллить embeddings_status; embeddings_status получил поле job_running.

4. ЧЕСТНОСТЬ vector-пути semantic_search: coverage{embedded,indexed_symbols} + note при частичном покрытии. Тест-символы понижаются ×0.7 (мягче keyword-пути 0.5 — косинус осмыслен, но тесты с описательными именами всё равно вытесняли реализацию) с over-fetch top_k*2 и пере-сортировкой.

ПРОВЕРЕНО live: embeddings build за ~30s/546 символов; store 1405→923 после prune; mode=vector coverage 923/923; MCP-цикл: reindex(1 файл) → фоновый sync → 924/924 за ~6s без блокировки; CLI revert → re-embed 3 символов. Тест prune_and_compact в kungfu-embed (dim-2, без движка).
