Этап 2: ожил граф вызовов и кросс-крейтовые импорты. На самом kungfu: relations выросли с 6 (только imports) до imports=131 + calls=778.

ЧАСТЬ 1 — workspace-импорты. resolve_import (kungfu-index/src/indexer.rs) раньше валил cross-crate `use kungfu_types::budget::Budget` в fuzzy stem-fallback по последнему сегменту ("Budget") → не резолвилось, coupling/affected/related были почти пусты. Добавлен build-time map crate_roots: import-имя→src-каталог, строится из путей вида "<dir>/src/...": "crates/kungfu-core/src/lib.rs"→"kungfu_core"→"crates/kungfu-core/src" (dash→underscore). Новая секция 0 в resolve_import резолвит crate_name::module::Item в {src}/module.rs | mod.rs | lib.rs (re-export). Imports 6→131.

ЧАСТЬ 2 — Calls-связи (Rust). Парсер: RawCall{caller_line, callee, is_method} + rust_parser::extract_calls обходит AST, держит enclosing function_item line (= symbol id line), вытаскивает callee из call_expression.function: identifier (free), scoped_identifier→name (path), field_expression→field (method, is_method=true), generic_function→рекурсия (turbofish). ParseResult.calls (Rust-only; др. языки []). 

Indexer::build_call_relations(files, symbols, file_calls): caller = by_file_line(file_id, caller_line); резолв callee по ИМЕНИ с приоритетом точности над полнотой:
- свободный/path вызов: единственное определение в том же файле (исключая самого caller) → link; иначе unique_global.
- method вызов: ТОЛЬКО unique_global (тип receiver неизвестен).
- unique_global = ровно один callable с этим именем во всём проекте, не сам caller.
- НЕОДНОЗНАЧНОЕ (несколько одноимённых, напр. 4×ask_context для service.ask_context()) → пропуск. Честная деградация из этапа 0 покрывает.
ГАРД ТОЧНОСТИ: is_ubiquitous_callable — стоп-лист вездесущих std/core имён (new/len/clone/to_string/from/iter/unwrap/map/push/get/... ~70). Без него `.len()` на Vec ошибочно липнет к единственному индексированному len (был EmbeddingStore::len), вес 1.0 → шум в callers/affected. Дроп этих имён: calls 1067→778.

Все Calls вес 1.0 (affected их учитывает, фильтр weight>=0.7). source_id/target_id — SYMBOL id (`s:fileid:line:name`), не file. В index_only старый фильтр old_relations по changed_file_ids ловил только file-level source; добавлен дроп symbol-level source по префиксу `s:{changed_file_id}:`, иначе старые Calls изменённых файлов накапливались.

ОГРАНИЧЕНИЕ: как и imports, all_calls собирается только для переиндексированных файлов — полный граф даёт index_full; инкременты частичны (консистентно с imports). Остальные 9 языков — пустой calls до отдельных экстракторов; callers/callees для них отдают диагностику этапа 0.
