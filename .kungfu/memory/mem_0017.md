Эпик 3 must-have плана (8j6rbb), v2.5.14. Call-извлечение распространено с Rust на остальные 9 языков.

АРХИТЕКТУРА: общий walker в crates/kungfu-parse/src/calls.rs (pub(crate)) вместо 9 дублированных обходчиков. CallSyntax{caller_kinds, call_kinds, callee: fn(Node,&str)->Option<(String,bool)>} — каждый язык задаёт таблицу + маленький резолвер callee. Walker ведёт enclosing caller line (узел из caller_kinds) и собирает RawCall. КРИТИЧНО: caller_kinds обязаны совпадать с узлами, из которых extract() языка делает Function/Method символы — привязка вызова к caller идёт по (file_id, start_line). rust_parser оставлен со своим walker'ом (работал, не трогали).

ТАБЛИЦЫ ПО ЯЗЫКАМ (узлы tree-sitter):
- TS/JS: caller function_declaration|generator_*|method_definition|arrow_function|function_expression|function; call_expression; callee: identifier (free) / member_expression→property (method)
- Python: function_definition; call; identifier / attribute→attribute
- Go: function_declaration|method_declaration; call_expression; identifier / selector_expression→field (pkg.F и recv.M синтаксически неразличимы → оба is_method)
- Java: method_declaration|constructor_declaration; method_invocation; name field, is_method=наличие object field
- C#: method_declaration|constructor_declaration|local_function_statement; invocation_expression; identifier / member_access_expression→name
- Kotlin (kotlin_ng): function_declaration; call_expression; named_child(0): simple_identifier (free) / navigation_expression→последний simple_identifier (method; helper calls::last_descendant_of_kind = max по start_byte)
- C: function_definition; call_expression; identifier / field_expression→field (fn-pointers в структурах)
- C++: как C + qualified_identifier→name (рекурсивно, ns::f → free) + template_function→name

СТОП-ЛИСТ is_ubiquitous_callable расширен по экосистемам (~70→180): JS (forEach/then/log/toString/require/...), Python (append/items/format/print/range/isinstance/str/dict/...), Go capitalized (Error/String/Printf/New/Close/...), Java/Kotlin (println/equals/hashCode/add/put/of/let/run/listOf/...), libc (printf/malloc/free/memcpy/strlen/...). Принцип тот же: уникально-индексированное имя не должно красть std-вызовы.

ВАЛИДАЦИЯ: 10 smoke-тестов в kungfu-parse (по одному на язык, общий helper assert_calls) + e2e full_index_builds_ts_call_relations в indexer. Реальные репо: flask (Python) 751 calls — get_root_path←Scaffold.__init__ корректно, ambiguous open_resource честно пропущен; gin (Go) 1546 calls — CreateTestContext←тестовые функции корректно. express (JS) только 5 — НЕ баг call-экстрактора: legacy assignment-style (exports.x=function) не извлекается как символ — заведена отдельная задача.

Итог: callers/callees/affected/edit_context(callees) работают на всех 10 языках при условии, что символы извлечены.
