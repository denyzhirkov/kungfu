Реализовано на worktree-ветке worktree-agent-ac2292440965c573b (коммит 8c77ce8, v2.5.25). Закрывает «Paused — needs design rethink» из BACKLOG: граф вызовов на реальных проектах взрывался (Go stdlib 1M рёбер) — теперь фильтрация на build-time, принцип «точность над полнотой» + retrieval honesty.

КОНФИГ [call_graph] в KungfuConfig (kungfu-config): enabled=true, cross_file_only=true, max_caller_files=25 (0 = выкл). Единая валидированная точка, без env.

СТОП-ЛИСТ: перенесён из indexer.rs в kungfu-index/src/stoplist.rs — ЕДИНАЯ таблица UBIQUITOUS: &[(&str, LangMask)] (~460 имён, было ~180), битмаска групп RUST/JS/PYTHON/GO/JVM/CSHARP/C_CPP/ALL, OnceLock<HashMap>. Lookup языкозависимый: is_ubiquitous_callable(name, lang файла caller'а); неизвестный язык фильтрует по всем группам (консервативно). is_stoplisted_name(name) — языконезависимый query-side чек.

ФИЛЬТРЫ: (1) cross_file_only и частотный срез применяются ПОСТ-МЁРЖ в Indexer::filter_call_graph_noise на всех трёх путях индексации (full/incremental/index_only) — правила действуют и на рёбра, унаследованные от неизменённых файлов, смена конфига вступает в силу на любом следующем индексе. (2) Частотный срез: callee с >N distinct caller-файлов → все входящие рёбра дропаются; счётчик в IndexStats::call_edges_filtered (CLI index output + MCP reindex response), debug-лог. (3) enabled=false вычищает Calls целиком.

СХЕМА ИНДЕКСА: kungfu-storage::INDEX_SCHEMA_VERSION=2, файл schema_version.json пишется каждым индекс-раном. ensure_fresh_index + index_incremental/index_paths/index_changed при mismatch (или отсутствии маркера у старых индексов) делают автоматический index_full — миграция = реиндекс.

ЧЕСТНОСТЬ: call_graph_provenance() (kungfu-core, config-aware строка) в callers/callees (MCP и CLI, non-empty и no_edges) и в новом поле AffectedResult.provenance. Пустые ответы различают статусы: call_graph_disabled / filtered_ubiquitous («"unwrap" is on the ubiquitous-callables stop-list… use search_text») / call_graph_not_indexed / no_edges. CLI callers/callees JSON унифицирован с MCP-формой {status,name,results,provenance} (был голый массив).

ЦИФРЫ на самом kungfu (94 файла): calls 989 → 482 (−51%), relations.json 137KB → 71KB. При max_caller_files=2 срез дропает ещё 301 ребро (482→181) — на маленьком репо дефолт 25 не срабатывает, валидация дефолта на гигантских репо (Go stdlib) остаётся открытой (отмечено в BACKLOG).

НЮАНС: callers(X) для X, вызываемого только в своём файле, теперь честно отдаёт no_edges с provenance — это by design, не баг.
