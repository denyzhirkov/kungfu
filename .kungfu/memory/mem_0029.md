После записи baseline-score-v4.json (v2.6.0) векторные стора всех kungfu-bench/* репо (embeddings.bin + манифесты, суммарно ~700MB: go 160M, HA 176M, deno 96M, django 64M, react 58M, ruff 20M и др.) удалены сознательно — это одноразовый артефакт оценки, не нужный quality-бенчмарку в keyword-режиме. Для будущего векторного A/B (кейсы категории concept-recall используют vector-слой) стора надо перестроить: `kungfu embeddings build` в каждом целевом репо, ~1 час CPU суммарно (go ~40-50 мин — самый долгий). Индексы (.kungfu/index/*.json) оставлены. Известный следующий рычаг concept-recall (из отчёта u93erp): оставшиеся провалы — не проблема блендинга, а терсость embed-текста name+signature+doc; нужны chunk/file-level embeddings.
