The MCP tool set is a deliberate contract, pinned by test `mcp_tool_set_is_the_consolidated_surface` (kungfu-mcp lib.rs); adding/removing a tool must update that list, MCP_INSTRUCTIONS (≤2048 chars, currently ~2031 — no room to grow without cutting) and README "Tools (23)". Principle: merge overlapping tools behind an explicit option, de-expose niche ones to CLI-only — never delete capability (CLI keeps every command). Merges: history = file_history+symbol_history+change_timeline (one exact file per response, uncached because git state changes without reindex); memory_search(empty query = list, filters kind/tag/pinned/status) + memory_update(status) replace memory_list/memory_archive; project_status carries embeddings readiness (file checks only, no model load); repo_outline(include_onboard); file_outline(budget>tiny = old explore_file); find_files = single ranked file search (path + contained symbols, `match` reason, scope before trim) — kungfu has NO text/literal content search, route that to Grep; investigate dropped (ask_context has changed_files); verify_change absorbs review (missing_co_changes confidence-filtered: count≥3, conf≥0.5, file ≥5 window commits, no lockfiles/hub files; risk = blast radius raised ≤1 level by co-changes; untested only adds a reason + evidence note). CLI-only: review, smart-test, test-subjects, commit-context, pr-context, investigate, onboard, stats, embeddings build, annotation-queue. Data at decision time: 258 calls on this repo, ~half the tools never called; schema bytes 22.5KB → 17.4KB.
