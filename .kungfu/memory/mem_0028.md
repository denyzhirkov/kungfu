ask_context Strategy A2 blends vector top-K for every intent and any 2+ keyword query. Empirically tuned on the 50-case bench with full embedding stores: bge-small cosine <0.65 is a noise band (dropped); 0.65-0.75 is a mid-band that only BACKFILLS (capped just below the best name-match score via VECTOR_TRUSTED_COS=0.75 + VECTOR_CAP_MARGIN); >=0.75 is trusted and scores on a linear ramp 0.6->0.9 (KUNGFU_W_VECTOR / _MIN / _STRONG). Bounds: fetch 20, admit <=10, <=1 per file (same-file siblings embed alike and displace the file's main keyword hit - sibling expansion is Strategy C's job). Displacement of weak-but-exact name hits by mid-cosine 'plausible guess' vectors was the main regression mode found; the trust cap fixed it (feature-understanding recovered from -10 to +0.5 vs baseline). Packet declares retrieval honesty: mode keyword+vector vs keyword_only + skip reason. Bench: aggregate 53.08->55.86, concept-recall 33.97->46.27, 39/50 passed.
