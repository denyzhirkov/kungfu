kungfu-git DiffBase { rev, has_commits } from diff_base(root): `git rev-parse --verify -q HEAD` exit status (NEVER match git stderr text — localized git breaks it); unborn HEAD → empty tree via `git hash-object -t tree --stdin` (no -w: read-only, SHA-256-safe). diff_changed_lines / deleted_files / changed_paths take &DiffBase, all `--relative --no-renames <base> --`. git_query checks exit status; failures are errors, not silent []. verify_change change set = hunks ∪ deleted ∪ untracked (pathspec-excludes .kungfu at any depth — init does not gitignore it) ∪ changed_paths (binary/mode-only → no_hunk_files). Lists capped at 50 with `<key>_note`. Blast radius: review.rs DepGraph built once per request (affected() = ensure_fresh_index + build + one walk); affected_for_lines walks ≤200 names with a note — calling the full affected() use case per name made 3k untracked files take 90s (now 0.25s). Rule: never call a use case (with ensure_fresh_index + store loads) inside a per-item loop. Follow-up mz8625: old kungfu_git::changed_files still uses literal HEAD; is_git_repo checks root/.git (nested roots bail).
