The four-tier file-knowledge layer from mem_0030 is fully shipped in v2.6.1 (commits 1cc597b, 718f8c8, b5dc3f2, 0a5dfe0, d7a6589). Invariants and lessons for future work on it:

1. PROVENANCE CHAIN: FileEntry.purpose_source = doc | agent | agent-stale. Authored module doc ALWAYS beats agent annotation (annotate_file returns stored_doc_wins); staleness is marked via content_hash mismatch on any index pass, never silently trusted. Heuristic tags live in a separate field (FileEntry.tags) — never mixed into purpose.

2. NOISE FILTERS ARE LOAD-BEARING: without the license/copyright filter react served 1825 files of "Copyright (c) Meta Platforms" as purpose. Any new module-doc convention must pass looks_like_license_header + the @-pragma check (kungfu-parse). Same class of lesson in the glossary: TEST SYMBOLS must be excluded from term counts AND definition sites (helpers::test_symbol_ids) — before that fix django's "model" resolved to a tests/ fixture class and go's glossary was int/func/foo.

3. SIDEcar STORE: .kungfu/annotations.json (AnnotationStore, path-keyed, atomic_write) is durable knowledge like memory/ — index shards are derived and rebuild from it via Indexer::apply_annotations on all three index paths. Schema bumps: v3 purpose, v4 tags, v5 purpose_source+annotations.

4. GLOSSARY IS COMPUTED, NOT STORED: build_glossary(symbols, agent_terms, exclude, limit) in kungfu-core/src/glossary.rs runs on demand inside onboard. Tuning knobs: GENERIC_WORDS stoplist (~350), min 3 symbols / 2 files, plural→singular fold, project-name exclusion. Validated on 8 bench ecosystems (django model/lookup, HA entity/flow/coordinator, spring-boot configuration/bean with Javadoc meanings).

5. FILE VECTORS: files with purpose or tags are embedded (id prefix f: vs s: in the shared store); semantic_search returns them as kind=file/match_type=vector-file; coverage counts split by prefix for honesty. ask_context A2 still ignores f: ids (open enhancement).

macOS deploy gotcha: overwriting ~/.local/bin/kungfu in place SIGKILLs on next run (signature cache) — rm before cp.
