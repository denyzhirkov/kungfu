Батч v2.6.0, 8 треков параллельными worktree-агентами, каждый через полный gate (test+clippy+fmt), merge последовательный с ручным разрешением конфликтов в kungfu-storage/lib.rs (cache×doctor) и kungfu-search/lib.rs (cache×expansion).

Итоги: (1) kungfu init --agent claude — turnkey-интеграция (.mcp.json + versioned rules block в CLAUDE.md + PostToolUse hook), шаблоны в kungfu-project/src/templates.rs; (2) плагин — marketplace-установка, SessionStart-hook инжектит правила, anti-drift тест plugin_sync.rs требует синхронного bump'а plugin.json при смене версии workspace; (3) doctor: 7 integration-проверок + store_meta.json стамп версии индекса; (4) process-scope кэш шардов (process_cache.rs): callers 25s → 220ms cold / 3.7ms warm на 1M рёбер; (5) фильтрация call-графа: cross-file-only, частотная отсечка 25 файлов, стоп-лист ~460 имён с LangMask, INDEX_SCHEMA_VERSION=2 с автоапгрейдом; −51% рёбер на самом kungfu; (6) бенчмарк 20→50 кейсов, pinned SHAs (bench-repos.lock.json), 3 бага харнесса починены; старый baseline 69.48 был невоспроизводим, честный старт 46.41; (7) query expansion (kungfu-search/expand.rs): identifier split + per-query IDF + ~80 групп синонимов, identifier-mismatch +8.6, concept-recall +5.5; (8) MMR-сборка пакета в kungfu-rank (SAME_FILE_DECAY 0.5, SAME_DIR_DECAY 0.85), over-selection +14.2.

Совместный итог качества: 46.41 → 50.88 (baseline-score-v3.json), 35/50 passed. Слабейшая категория по-прежнему concept-recall (~33) — на неё запущена задача u93erp (векторные кандидаты в ask_context).
