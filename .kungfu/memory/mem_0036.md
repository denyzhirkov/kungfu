Issue #1 / PR #2+#3: commit_changed_lines/commit_files/commit_meta (kungfu-git) передавали hash из MCP commit_context в `git show` позиционно → `--output=<path>` = запись произвольного файла (воспроизведено). Фикс: validate_hash — 4..=64 hex (64 = SHA-256 репо). --end-of-options сознательно НЕ используется: hex уже исключает ведущий '-', а флаг ломает git < 2.24.

КОНВЕНЦИЯ: любой аргумент из MCP/CLI, попадающий в Command::new("git"), — либо после `--` (пути: file_log, blame_lines уже так), либо строго валидирован (ревизии). Риск реальный: у пользователей mcp__kungfu часто в auto-allow, т.е. prompt-injection обходит permission prompt. Регресс-тест: kungfu-git tests::option_shaped_hash_never_reaches_git.
